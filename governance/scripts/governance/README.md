# Governance Validators

Chạy từ thư mục gốc của repository:

```bash
python governance/scripts/governance/validate_structure.py
python governance/scripts/governance/validate_project_state.py
```

Các script này cung cấp mức thực thi tối thiểu bằng máy (minimum machine enforcement).

Chúng KHÔNG thay thế cho:
- test thực tế,
- kiểm thử bảo mật,
- CI,
- rà soát bởi con người/rà soát độc lập.
